# Leads

A **lead** is not a finding.

The writeups in the root of this repository are published research: measured, with
enough trials to attach confidence intervals, reproducible, and stated at the precision
the evidence supports. This directory holds the other thing — work that is real,
honestly recorded, and **not yet strong enough to claim anything**.

The distinction is the whole point of keeping them apart:

| | Finding | Lead |
|---|---|---|
| Trial count | Meets the standard (256/condition) | Below it, often n=1 |
| What it establishes | What is true | Whether it is worth investigating |
| Where it belongs | Repository root, cindrasec.com/research/ | Here |
| Safe to cite as a result | Yes | **No** |

A lead gets recorded rather than discarded because the expensive part of research is
usually the experimental design, not the runs. A design proven to work end to end is
worth keeping even when the sample size is one.

Every document here states its own limitations before its results, and carries the
honest one-sentence version for any external use. If you are quoting from this
directory, quote that sentence — not the numbers.
